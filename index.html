개인정보 처리방침 — 쌍인

시행일: 2026-10-17

쌍인(이하 "앱")은 문서에 서명·도장을 넣는 앱입니다. 운영자는 이용자의 개인정보를 수집하거나 서버로 전송하지 않습니다. 앱은 인터넷 권한(INTERNET)을 요청하지 않으며, 모든 처리는 이용자의 휴대폰 안에서만 이루어집니다.

앱이 기기 안에 저장하는 정보

정보용도저장 위치
직접 그린 서명, 만든·가져온 도장 이미지문서에 찍기앱 내부 저장소
찍은 기록 (문서 이름, 문서번호, 저장 날짜·형식, 사용한 도장 작은 그림)이용자가 확인하는 사용 내역. 설정에서 끄거나 지울 수 있음. 문서 내용은 기록하지 않음앱 내부 저장소
디지털 서명용 키와 인증서PDF 디지털 서명. 키는 기기의 보안 영역(Android Keystore)에 있으며 앱 밖으로 꺼낼 수 없음. 사용할 때마다 지문·얼굴·화면 잠금 인증을 요구함Android Keystore / 앱 내부 저장소
  • 위 정보는 앱 내부 저장소에만 있어 다른 앱이 읽을 수 없고, 클라우드 백업(allowBackup=false)에도 포함되지 않습니다.
  • 앱을 삭제하면 위 정보도 함께 삭제됩니다.
  • 사진 문서나 카메라 촬영 사진(도장 사진 가져오기)은 이용자가 직접 선택하거나 촬영한 경우에만 앱이 읽으며, 원본 파일은 수정하지 않습니다.

임시 문서와 보관

  • 문서를 열거나 변환할 때 원본·복호화 사본·미리보기 파일이 앱 캐시에 만들어집니다. 정상적으로 문서를 닫으면 해당 작업 파일을 삭제합니다.
  • 비정상 종료 후 남은 작업 파일과 공유용 사본은 다음 앱 시작 시 24시간이 지난 파일부터 정리합니다. 저장 공간 관리에서 앱 데이터를 삭제하면 내부 저장 정보도 제거됩니다.
  • 이용자가 직접 외부 폴더에 저장하거나 공유한 파일은 앱 삭제로 지워지지 않습니다.

앱이 요청하는 권한

  • 생체 인증(USE_BIOMETRIC·USE_FINGERPRINT): 디지털 서명을 쓸 때 본인 확인 창을 띄우는 데만 사용합니다. 지문·얼굴 정보는 앱이 받지 못하고, 기기가 인증 성공 여부만 알려 줍니다.
  • 그 밖의 권한(인터넷, 저장소, 연락처, 위치 등)은 요청하지 않습니다.

이용자가 직접 내보내는 파일

  • 저장한 문서(PDF·이미지·한글 파일)와 "찍은 기록 내보내기" 파일(.json)은 이용자가 고른 위치에 저장됩니다. 이 파일에는 문서 이름·문서번호가 포함되므로 보관과 공유는 이용자가 직접 관리합니다.

제3자 제공·광고·분석

  • 광고·분석·개인정보 수집 SDK를 사용하지 않습니다. 문서 처리와 화면 구현을 위한 오픈소스 라이브러리를 사용하며, 목록은 앱의 오픈소스 라이선스 화면에서 확인할 수 있습니다. 개인정보를 제3자에게 제공하지 않습니다.
